# nematx-wipetower

Wipe tower manager of the NematX printers. It is selected by
`step_wipetower_plugin = nematx_wipetower`; the host's default manager stays the
default choice.

Without a NematX setting, it builds the same tower as the host's default manager
(`wipe_tower.manager.default`): same towers (global and per instance), same purge
bands, same brim, perimeter, cone and fill of the unused area, so the same G-code.
The wipe services of the host (tool-change purge, unload, ramming) are unchanged:
the host lends them to the selected manager.

## Settings

The package defines these object settings, overridable per object like the other wipe tower settings:

- `wipe_tower_perimeters` (default 1): number of perimeter loops around the tower.
  1 is the default manager's loop around the purge bands (and the cone ring when there is a cone);
  each further loop is one line spacing outside the previous ones, and the brim starts outside the
  last one; 0 prints no loop and keeps the purge, the fill and the brim.
- `wipe_tower_separate_filament` (default off): each tool purges in its own section of the tower
  depth, with its own perimeters and fill, so that incompatible materials never need to stick
  together. The sections are planned once for the whole print and keep their place: each one is as
  deep as the most that its tool purges on one layer, they follow each other by tool number, and a
  gap keeps room for the perimeters of two neighbouring sections. A section is printed on every
  layer, from the first one until the last layer where its tool prints something of the tower's
  objects (at most until the last tool change): the tool visits the tower on the layers where it
  prints nothing else. The brim surrounds every section; the cone setting is ignored. It is refused
  with `single_extruder_multi_material` and with `filament_multitool_ramming`.

## Sources

- `src/WipeTowerManager.cpp`: the `STEP_WIPETOWER` manager.
- `src/WipeTowerLayout.*`: bands and tower layers, copied from the host.
- `src/FilamentSections.*`: section places of `wipe_tower_separate_filament`.
- `src/TowerFootprints.*`: towers and their position, from the Print's settings.
- `src/TowerFlow.hpp`: the rounded line flow of the host's `Flow`.
- `src/rectilinear/`: reviewed copy of the host's Monotonic and Grid fills,
  generated by `tools/import_rectilinear.py` from a pinned host revision.

## Limitations

- The name of an instance tower numbers the instance among the printable instances
  of its object; the host numbers it among all the model instances, printable or not.
- The host's tower footprint (collision check, preview) is the `wipe_tower_width` square plus
  the brim: it does not include the perimeters beyond the first one, nor the depth of separate
  sections beyond that square.

## Tests

- `tests/kernel_tests.cpp` (CTest `wipetower_kernel`): section planning.
- `tests/test_import.py` (CTest `wipetower_import`): the copied fills are
  reproduced from the pinned host files.
- `tests/test_wipetower.py`: exports a two-tool model with both managers and
  compares the G-code, one tower setting at a time; checks the loops added or removed by
  `wipe_tower_perimeters`; checks that separate sections never overlap, keep their place and are
  printed where their tool prints nothing else, and the refusal with one nozzle.

```
cmake --build .build --config Debug --target nematx_wipetower
python plugins/wipetower/tests/test_wipetower.py --host-executable "C:/path/to/build/src/Debug/Slic3r_console.exe" --runtime-path "C:/path/to/deps/usr/local/bin"
```
